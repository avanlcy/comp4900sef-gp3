# Dead Fire Phase 5 (Menus & Meta) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Every graph-authoring step is automation through the generator pipeline; the only **(person)** step is the playtest in Task 7. The project manager chose native execution without a question round (as in Phases 3 and 4): the agent implements every task in this session and one fresh reviewer reads the result at the end.

**Goal:** A main menu with vehicle and track selection, three cars that drive differently, a second track, saved progress with unlock rules, a pause menu, a summary that reports unlocks, and settings (volume, difficulty, fullscreen), all generated and tested through the existing Blueprint pipeline.

**Architecture:** Every Blueprint is described in Python under `tools/bpgen/graphs/`, generated into `comp4900sef/Script/paste/<Asset>/` by `tools/bpgen/generate_all.py`, and applied inside the running editor by `comp4900sef/Script/df_apply_blueprint.py` through the DF Blueprint Authoring plugin. Phase 5 adds a meta layer (`meta.py`: SaveGame + GameInstance with the vehicle and level catalogues, progress, settings, navigation), a menu layer (`menus.py`: menu GameMode and PlayerController, five widgets), vehicle children with stats (`vehicle.py`), a per-level GameMode child and the race hooks (`game_mode.py`: player vehicle class, difficulty, result recording, unpause), the pause action (`racer.py`), summary changes (`hud.py`), a test module (`tests_menu.py`), and three levels in the level builder (`L_MainMenu`, `L_Switchback`, the existing two). The pipeline itself gains three small things (Task 0): an input action that fires while paused, class-default overrides on an inherited component, and support assets a manifest requires.

**Tech Stack:** UE 4.27.2 at `D:\UE_4.27`, Blueprint-only project `comp4900sef/comp4900sef.uproject`, PhysXVehicles, UMG (Button, Slider, TextBlock), SaveGame / GameInstance / GameUserSettings, SoundMix, Functional Testing framework, editor Python 3.7 reached with `python tools/ue_remote.py --code "..."`, headless tests with `tools/run_tests.ps1`.

**Spec:** `docs/superpowers/specs/2026-10-30-phase5-menus-design.md` (flow and levels §2, vehicles §3, progress §4, menus §5, polish §6, values §7, tests §8, acceptance §10). Earlier designs: `docs/superpowers/specs/2026-10-20-dead-fire-design.md`, `2026-10-21-phase2-race-flow-design.md`, `2026-10-30-phase3-items-design.md`, `2026-10-30-phase4-ai-design.md`.
